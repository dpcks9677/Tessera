# 스킬·에이전트·게이트 작성

- 규칙 본문은 원본 한 곳에만 둡니다. 스킬·에이전트·게이트에는 원본 경로와 한 줄 요지만 적습니다. 색 값, 모듈 목록, 테스트 개수처럼 바뀌는 값은 복사하지 않습니다.
- 판정 어휘는 `.claude/gates/README.md` 의 `PASS` / `CONCERNS` / `NOT ASSESSED` / `FAIL` 넷만 씁니다. 새 어휘를 만들지 않습니다.
- 위임 프롬프트에 실을 맥락은 `CLAUDE.md` 「오케스트레이션 › 규칙」을 따릅니다.
- 에이전트에게 규칙을 지키게 하려면 정의 파일에 "이 규칙 파일을 읽으라"는 한 줄과 경로를 둡니다. 경로별 규칙은 서브에이전트에서도 범위 파일을 `Read` 할 때 주입되지만(2026-10-22 실측), 그 전에 내리는 판단에는 닿지 않습니다.
- `SKILL.md` 는 500줄 이하로 둡니다. 세부 절차는 같은 폴더의 `references/` 로 빼고, `SKILL.md` 에 어느 단계에서 그 파일을 읽는지 적습니다. 적지 않은 보조 파일은 로드되지 않습니다.
- 규칙 파일의 frontmatter는 `paths` 하나만 씁니다. 다른 필드는 읽히지 않습니다.
- 모델 티어(설계 opus, 판단·수정 sonnet, 양식이 정해진 일 haiku)는 `CLAUDE.md` 오케스트레이션 절을 따릅니다.
- 새 에이전트·스킬의 인식 시점은 `CLAUDE.md` 「새 에이전트·스킬 등록 시점」을 따릅니다.
- 본문은 한국어로 씁니다.
