# 증강 카드 디자인 수정 계획

## 1. 목적

증강 선택 창과 스톤 트레이의 보유 카드가 서로 다른 디자인 단계에 머물러 있는 문제를 해소한다. **현재 증강 선택 창의 카드 정보 구조와 가로 비율을 기준 디자인으로 고정**하고, 선택 카드와 보유 카드가 같은 원본 프리셋·안전 영역·상태 표현을 사용하도록 통일한다.

이번 작업은 카드 외형과 표시 계층만 수정한다. 증강 효과, 점수 계산, 드래프트 규칙, 카드 선택 수, 트레이 구조는 변경하지 않는다.

## 2. 레퍼런스 해석 원칙

두 번째 제공 이미지는 다음 시각 문법만 참고한다.

- 펼쳐진 직사각형 종이와 한쪽의 말린 종이가 한 장처럼 연결되는 구조
- 말린 종이의 겹, 눌린 중앙 실루엣, 가죽 띠와 인장으로 생기는 깊이감
- 오래된 종이의 얕은 찢김과 가장자리 마모
- 종이 본문과 장식 영역의 명확한 분리

이미지의 원본 픽셀, 문양, 텍스트, 손상 위치, 실루엣을 복사하거나 2D 에셋으로 재사용하지 않는다. 모든 메시·텍스처·인장 문양은 Tessera의 스타일에 맞춰 새로 제작한다.

## 3. 현재 구현 상태와 수정 방향

### 3.1 확인된 현재 상태

- 선택 창은 `AugmentCardView`와 `AugmentParchmentVisuals.GetSprite`가 만드는 2D 양피지 스프라이트를 사용한다.
- 보유 카드는 `AugmentTrayCardView`가 `AugmentScrollModelFactory`의 정적 3D 프리팹을 배치하고, 동일한 `AugmentCardView`의 정보만 High-Res Overlay로 투영한다.
- 따라서 이름·설명·상태 정보는 일부 공유하지만, 종이 외곽과 말림은 서로 다른 생성 경로를 사용한다.
- 현재 프리셋은 5종이며 외곽 굴곡이 커서 카드가 직사각형보다 물결 모양 양피지로 읽힌다.
- 현재 3D 말림은 별도 롤 메시로 구성되어 있으나 게임 카메라에서 얇은 막대처럼 뭉쳐 보이는 문제가 기록되어 있다.
- 카드 프리셋 ID는 드래프트 선택값에서 보유 카드와 랜덤 박스 결과까지 전달된다.

### 3.2 통일 원칙

선택 창 카드를 기준으로 다음 하나의 시각 사양을 사용한다.

```text
공통 카드 프리셋 4종
├─ 선택 창: 동일 3D 원본의 정면 베이크 스프라이트 + 공통 정보 UI
└─ 스톤 트레이: 동일 3D 프리팹 + 공통 정보 UI 오버레이
```

- 메시 생성 규칙, 종이 재질, 말림, 띠, 인장, 내부 테두리, 안전 영역은 한 곳에서 정의한다.
- 선택 창에서는 런타임 3D 카메라를 추가하지 않고, 에디터에서 같은 프리팹을 정면 렌더한 투명 스프라이트를 사용한다.
- 트레이에서는 같은 프리팹을 현재 슬롯 앵커에 배치한다.
- 정보 UI는 두 화면 모두 `AugmentCardView`를 유지하되 동일한 정규화 안전 영역을 적용한다.

## 4. 확정 디자인 사양

### 4.1 카드 본체

- 전체 점유 영역은 기존 가로형 비율 `1.774:1`을 유지하되, 직사각형 카드 외형은 오른쪽의 펼쳐진 본문에만 적용한다.
- 기존 상·하단의 큰 물결과 삐뚤삐뚤한 금색 아웃라인을 제거한다.
- 펼쳐진 종이 본체는 평평한 직사각형을 기본으로 하고, 외곽 알파/메시에는 작은 찢김과 섬유 빠짐만 넣는다. 왼쪽 말림 뒤에는 직사각형 종이 판을 깔지 않는다.
- 찢김은 카드 전체 폭·높이의 약 `0.5~1.5%` 범위로 제한해 멀리서 직사각형으로 읽히게 한다.
- 네 모서리와 가장자리의 찢김 위치만 다르게 한 **4종 종이 프리셋**을 제작한다.
- 종이 질감은 따뜻한 양피지색, 넓고 낮은 대비의 얼룩, 약한 섬유 결만 사용한다. 반복되는 실사 노이즈와 강한 PBR 요철은 사용하지 않는다.

### 4.2 내부 테두리

- 종이 가장자리 안쪽에 한 줄의 얇은 테두리를 둔다.
- 기준색은 태서렉트의 시안 계열을 낮은 강도로 변형한 `#5EDCFF` 전후로 하고, 과노출되지 않는 약한 발광을 사용한다.
- 선 두께는 선택 창 기준 `1~2 px`, 트레이의 `640×360` 내부 렌더 기준 최소 `1 px`이 남도록 조정한다.
- 외곽 찢김을 따라 흔들리지 않고, 직사각형 정보 영역을 안정적으로 감싸는 선으로 제작한다.
- 선택·충돌·사용 완료 상태는 기존 상태색을 유지하되 내부 시안 선 자체의 정체성을 덮지 않도록 밝기와 알파만 보조 조정한다.

### 4.3 왼쪽 말림 장식

- 말린 부분은 카드 왼쪽에 세로축으로 배치하고 펼쳐진 본체의 왼쪽 경계와 이음매 없이 연결한다. 말림의 위·아래 끝은 펼쳐진 직사각형보다 약간 돌출되고 불규칙하게 퍼진다.
- 봉 또는 금속 축은 구현하지 않는다.
- 단면에서 약 `2.5바퀴`의 종이층이 식별되어야 한다.
- 완전한 원통 대신 위·아래가 조금 넓고 중앙이 안으로 들어간 실패형 실루엣으로 만든다. 절차형 메시 또는 변형한 실린더 메시를 사용할 수 있다.
- 말림 폭·높이·겹 간격은 실제 비율보다 과장하되, 별도의 `Pixel Readable Roll Layers` 보조 메시는 사용하지 않고 2.5바퀴 말림 본체만으로 표현한다.
- 겹 안쪽은 종이 앞면보다 어둡게 하고, 밝은 외곽 림과 접촉 그림자를 분리해 픽셀 필터 후에도 말림이 읽히게 한다.
- 미세 섬유로 말림을 설명하지 않고 큰 실루엣, 단계형 명암, 겹 간 간격으로 표현한다.

### 4.4 가죽 띠와 붉은 인장

- 말림 중앙의 들어간 부분을 짙은 갈색 가죽 띠가 한 바퀴 감싼다.
- 띠는 종이와 명도·색상 차이가 충분해야 하며 별도 리본 꼬리는 만들지 않는다.
- 띠 위에 딥 크림슨 계열의 붉은 밀랍 인장을 배치한다.
- 인장 중앙 문양은 Tessera를 상징하는 **정육면체** 양각으로 새로 제작한다.
- 원거리 가독성을 위해 인장과 정육면체 문양은 실제 비율보다 크게 만들고, 문양은 미세한 선각 대신 면이 분명한 저해상도 실루엣을 사용한다.
- 기존 원형 인장 상태 틴트는 유지하되 선택 상태가 정육면체 문양을 지우지 않도록 별도 머티리얼 프로퍼티로 색만 변경한다.

### 4.5 정보 안전 영역

- 말림·띠·인장은 장식 전용 영역으로 지정하며 텍스트와 아이콘을 출력하지 않는다.
- 카드 왼쪽 약 `20~24%`를 장식 거터로 예약한다.
- 이름, 종류, 상태, 아이콘, 한 줄 효과, 대상 표시는 나머지 오른쪽 `76~80%` 안에서 기존 선택 창의 계층을 유지한다.
- `AugmentCardView`에 공통 `Content Root`를 두고 선택 창과 트레이 오버레이가 같은 앵커·여백을 사용하게 한다.
- 트레이 오버레이 앵커도 이 안전 영역의 네 모서리에 맞춰 갱신한다.

## 5. 4종 프리셋 구성

네 프리셋은 카드 크기, 말림 크기, 띠·인장 위치, 내부 테두리, 정보 안전 영역을 공유한다. 차이는 종이 외곽의 작은 손상 패턴에만 둔다.

| ID | 프리셋 | 차이 |
|---|---|---|
| 0 | 기본 마모 | 우상단과 좌하단에 짧고 얕은 섬유 빠짐 |
| 1 | 상단 찢김 | 상단 2곳의 작은 V자 찢김과 우측 가장자리 마모 |
| 2 | 하단 찢김 | 하단 2곳의 비대칭 찢김과 좌측 연결부의 눌림 |
| 3 | 모서리 마모 | 우상단·우하단 모서리의 둥근 마모와 짧은 균열 |

- 손상은 정보 안전 영역과 내부 테두리를 끊지 않는다.
- 3장의 드래프트 선택지에는 가능한 한 서로 다른 프리셋을 배정한다.
- 기존 저장/진행 상태의 프리셋 `4`는 프리셋 `3`으로 변환해 카드 외형만 안전하게 이관한다.

## 6. 구현 대상

### 6.1 공통 프리셋과 2D 선택 카드

- `AugmentParchmentVisuals.cs`
  - 프리셋 수를 5종에서 4종으로 변경한다.
  - 큰 물결 외곽 생성과 금색 외곽선을 제거한다.
  - 직사각형 기반의 4종 미세 손상 프로필과 공통 정보 안전 영역을 정의한다.
  - 런타임 절차형 전체 카드 스프라이트 대신 베이크된 정면 프리뷰 스프라이트 로딩을 우선한다.
- `AugmentCardView.cs`
  - 모든 정보 요소를 공통 `Content Root` 아래로 이동해 왼쪽 장식 거터를 비운다.
  - 기존 `Outline`을 카드 외곽 장식으로 사용하지 않고 상태 피드백용 얇은 글로우/강조로 제한한다.
  - 선택 창과 보유 카드가 동일한 정보 배치와 상태 표현을 사용하도록 한다.

### 6.2 3D 카드와 에셋 생성

- `AugmentScrollModel.cs`
  - 펼쳐진 본체를 직사각형 기반으로 다시 만들고 미세 손상만 프리셋별로 적용한다.
  - 왼쪽 말림을 약 2.5바퀴, 중앙이 들어간 실패형 단면으로 재구성한다.
  - 기존 리본 꼬리 메시를 제거하고 가죽 띠 재질 슬롯을 분리한다.
  - 정육면체 양각이 포함된 붉은 인장 메시를 적용한다.
  - 내부 시안 테두리용 별도 얇은 메시 또는 발광 데칼을 추가한다.
  - 오버레이 앵커를 장식 거터 오른쪽의 안전 영역으로 맞춘다.
- `AugmentScrollAssetGenerator.cs`
  - 종이 앞/뒤, 가죽, 밀랍, 내부 시안 선 재질을 생성한다.
  - 4종 프리팹과 선택 창용 정면 프리뷰 스프라이트를 같은 원본에서 함께 베이크한다.
  - 기존 5번째 프리팹은 새 프리셋 생성 검증이 끝난 뒤 제거한다.
- `Assets/Resources/AugmentScrolls`
  - 프리팹 4종, 공통 재질, 메시, 프리뷰 스프라이트를 저장한다.

### 6.3 런타임 연결과 프리셋 이관

- `AugmentTrayCardView.cs`
  - 현재 정적 프리팹 로딩과 High-Res Overlay 구조는 유지한다.
  - 공통 안전 영역과 내부 테두리 상태를 동기화한다.
- `AugmentedYachtController.cs`
  - 선택 창 카드가 같은 프리셋의 베이크 프리뷰를 사용하도록 연결한다.
- `YachtAugmentRuntime.cs`
  - 카드 프리셋 후보를 `0~3`으로 변경한다.
  - `NormalizeCardPreset(4)`는 `3`으로 이관하고 나머지 범위 밖 값은 `0`으로 폴백한다.
  - 선택 프리셋의 보유 카드·랜덤 박스 상속은 기존 방식 그대로 유지한다.

## 7. 구현 순서

1. 선택 창 카드의 현재 크기·정보 계층을 기준선으로 캡처하고 왼쪽 장식 거터 및 본문 안전 영역을 확정한다.
2. 프리셋 0의 직사각형 본체, 얇은 시안 내부선, 2.5바퀴 실패형 말림을 무재질 블록아웃으로 제작한다.
3. 메인 게임 카메라와 `640×360` 픽셀 필터에서 말림의 겹과 중앙 눌림이 읽히도록 비율·명암을 조정한다.
4. 가죽 띠와 정육면체 양각 붉은 인장을 추가하고 텍스트 안전 영역 침범 여부를 확인한다.
5. 동일한 기준에서 외곽 손상만 변경한 나머지 3종을 제작한다.
6. 공통 종이·가죽·밀랍·시안 발광 재질을 연결하고 4종 정적 프리팹을 생성한다.
7. 각 프리팹의 정면 프리뷰 스프라이트를 베이크해 선택 창 배경으로 연결한다.
8. `AugmentCardView` 정보 요소를 공통 안전 영역에 재배치하고 트레이 오버레이 앵커를 같은 영역으로 맞춘다.
9. 프리셋 배정 범위를 4종으로 변경하고 기존 ID `4` 이관을 적용한다.
10. 선택 창 → 선택 완료 → 트레이 표시 → 랜덤 박스 교체의 외형 연속성을 회귀 검증한다.

## 8. 테스트 및 완료 기준

### 8.1 자동 검증

- 프리셋 개수와 정규화: `0~3` 유지, 기존 `4 → 3`, 그 외 잘못된 값 `→ 0`.
- 드래프트 3장에 중복 없는 프리셋이 배정된다.
- 선택한 프리셋 ID가 보유 카드와 랜덤 박스 교체 결과까지 유지된다.
- 프리팹 4종과 대응 프리뷰 스프라이트 4종이 모두 로드된다.
- 각 프리팹에 본체, 말림, 가죽 띠, 인장, 내부 테두리, 안전 영역 앵커가 존재한다.
- 말림 메시의 회전량이 약 2.5바퀴이며 중앙 반경이 양끝보다 작다.
- 인장에 정육면체 문양 메시가 존재하고 봉·리본 꼬리 오브젝트는 존재하지 않는다.
- 선택 창과 트레이 카드의 정보 요소가 같은 정규화 안전 영역을 사용한다.
- 일반 요트 모드에서는 증강 카드 프리팹과 오버레이가 생성되지 않는다.

### 8.2 시각 검수

- 선택 창과 트레이 카드가 같은 프리셋으로 즉시 식별된다.
- 카드 본체는 첫인상에서 직사각형이고, 가까이서만 4종의 찢김 차이가 보인다.
- 기존의 굵은 금색·물결형 외곽선이 보이지 않는다.
- 내부 시안 선은 얇고 은은하며 종이 텍스트보다 먼저 튀어나오지 않는다.
- `640×360`에서 별도 보조 레이어 없이 2.5바퀴 말림 본체와 중앙 눌림이 식별된다.
- 가죽 띠와 붉은 인장, 정육면체 문양이 게임 카메라에서 구분된다.
- 말림·띠·인장 위에 텍스트와 아이콘이 겹치지 않는다.
- 선택 가능, 선택됨, 보유, 충돌, 사용 완료, 비활성 상태가 기존과 동등 이상으로 구분된다.

### 8.3 검증 캡처

- 선택 창의 프리셋 3종 동시 표시
- 같은 선택 프리셋이 스톤 트레이에 배치된 전후 비교
- 트레이의 4종 강제 표시 근접 캡처
- `640×360` 픽셀 필터 적용 전·후의 말림 비교
- 선택/충돌/사용 완료 상태 비교

## 9. 범위 제외 및 보호 항목

- 제공 레퍼런스 이미지를 프로젝트 에셋으로 복사하거나 가공해 사용하지 않는다.
- 증강 아이콘 49종, 증강 효과 로직, 점수 계산, 드래프트 시점과 선택 규칙은 수정하지 않는다.
- 스톤 트레이 모델과 슬롯 수·크기는 변경하지 않는다.
- 텍스트 선명도를 위한 High-Res Screen Overlay 구조는 유지한다.
- 메인 씬은 새 오브젝트를 영구 배치하는 방식으로 수정하지 않고 기존 런타임 생성 구조를 유지한다.
- 기존 5종 구현 문서는 작업 이력으로 보존하고, 이 문서를 후속 디자인 수정의 우선 기준으로 사용한다.

## 10. 구현 결과 (2026-08-27)

- 상태: `DONE`
- 펼쳐진 오른쪽 종이만 직사각형 카드로 구성하고, 왼쪽 말림 뒤에는 별도의 직사각형 판이 보이지 않도록 재조형했다.
- 왼쪽에는 중앙이 들어간 약 2.5바퀴 말림, 가죽 띠, 정육면체 문양의 붉은 인장을 배치했다. 철 봉과 리본 꼬리는 구현하지 않았다.
- 종이 외곽 손상 4종과 얇은 시안 내부선을 같은 3D 원본에서 프리팹·선택 창 프리뷰로 생성했다.
- 선택 창과 스톤 트레이가 같은 프리셋과 본문 안전 영역을 사용하며, 말림 장식에는 텍스트가 출력되지 않는다.
- 제공된 참조 이미지는 형태와 실루엣 판단에만 사용했으며 프로젝트 에셋으로 복사·가공하지 않았다.
- 검증 결과: 카드 전용 EditMode `24/24`, 전체 EditMode `60/60` 통과. Play Mode에서 양쪽 드래프트 선택과 트레이 배치를 확인했으며 콘솔 오류는 `0`건이었다.
