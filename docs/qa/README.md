# QA 기록

> **문서 종류**: 기록 규칙 (사람·AI 대상)
> 이 폴더의 개별 기록은 시점 기록입니다. 작성 뒤 코드가 바뀌어도 본문을 고치지 않고, 버그 기록의 상태와 종료 기록만 갱신합니다.

버그, 플레이테스트, 밸런스 점검 기록을 둡니다. 계획서(`plan/`)와 달리 할 일을 지시하지 않습니다. 기록에서 나온 후속 작업은 사용자 확인을 받아 계획서 태스크로 옮깁니다.

## 폴더

| 폴더 | 파일 이름 | 만드는 스킬 |
|---|---|---|
| `bugs/` | `BUG-nnnn.md` (4자리 연번, 재사용하지 않음) | `/tessera-bug-report` |
| `playtests/` | `YYYY-MM-DD-<짧은-영문-슬러그>.md` | `/tessera-playtest-report` |
| `balance/` | `YYYY-MM-DD-<대상>.md` | `/tessera-balance-check` |

## 버그 상태

| 상태 | 뜻 |
|---|---|
| `OPEN` | 기록됨. 수정이 확인되지 않음 |
| `CLOSED` | 확인으로 수정이 입증됐거나, 재현 불가·의도된 동작·중복으로 종료. 종료 기록에 사유를 남김 |

확인(`verify`) 판정은 `.claude/gates/README.md` 의 판정 어휘를 씁니다. `PASS` 면 `CLOSED` 로 바꾸고, 그 밖의 판정은 `OPEN` 을 유지합니다.

## 버그 심각도

| 심각도 | 기준 |
|---|---|
| `S1` | 게임을 끝까지 진행할 수 없음, 점수·승패 오계산, 크래시, 데이터 손실 |
| `S2` | 규칙이 틀리게 동작하나 우회해 진행할 수 있음 |
| `S3` | 표시·연출·입력 반응이 틀림. 규칙 결과는 맞음 |
| `S4` | 오탈자, 사소한 시각 결함 |

## 버그 영역

`규칙`(`Games/*/Logic`, `Games/Yacht`), `프레젠테이션`(`Games/*/Presentation`), `주사위`(`Dice`), `테이블`(`Tabletop`), `렌더링`(`Rendering`, 셰이더), `에디터 도구`(`Assets/Editor`), `기타`.
