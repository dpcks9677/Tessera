# M7 증강 그래픽 에셋 인벤토리

## 1. 목적과 판정 기준

이 문서는 원본 증강 55개의 카드, 아이콘, 특수 주사위 외형, 런타임 VFX 필요 여부를 정의한다.

- **카드**: 55개 모두 공통 양피지 카드가 필요하다. 활성 45개는 게임에서 사용하고, 삭제 6개와 미구현 4개는 쇼케이스에서 비활성 사유와 함께 표시한다.
- **아이콘**: 활성 45개와 미구현 4개는 고유 문양을 사용한다. 삭제 6개는 제작 비용을 줄이고 폐기 상태를 즉시 전달하도록 공통 `삭제됨` 문양 하나를 공유한다.
- **주사위**: 활성 규칙에서 전용 주사위 타입을 만드는 6개만 개별 외형이 필요하다. 미구현 `strange-die` 모델은 리워크 확정 뒤로 미룬다.
- **VFX**: 활성 45개는 등장·획득 공통 VFX와 아래 행의 발동 프로필을 사용한다. 삭제·미구현 항목에는 런타임 VFX를 만들지 않고 비활성 카드 오버레이만 사용한다.
- **표기**: `공통`은 공통 카드/VFX 시스템의 프리셋을 뜻하며 증강별 전용 프리팹을 뜻하지 않는다.

## 3. 공통 제작 단위

### 카드와 아이콘

- 카드 프레임 1종: 양피지 바탕, 딥 크림슨 테두리, 앤틱 골드 켈틱 트림.
- 상태 오버레이 5종: 선택 가능, 선택됨, 충돌, 사용 완료, 비활성.
- 고유 아이콘 49종: 단색 마스크를 기본으로 하며 카드 강조색과 발동 VFX에서 함께 재사용한다.
- 삭제 공통 아이콘 1종: 삭제된 6개 카드가 함께 사용한다.
- 비활성 사유 배지 2종: `삭제됨`, `미구현`.

### 아이콘 제작 산출물과 순서

| 순서 | 산출물 | 규격·처리 |
|---:|---|---|
| 1 | 문장형 원본 | 단색 실루엣, 각진 절단, 네거티브 스페이스 중심의 해상도 독립 원본 |
| 2 | 자동 픽셀 초안 | 원본을 64×64px로 래스터화하고 안티앨리어싱 제거·흑백 임계값 적용 |
| 3 | 제한 팔레트 초안 | 단색 마스크 또는 투명색 포함 최대 5색으로 양자화 |
| 4 | 수동 보정본 | 고립된 1픽셀 제거, 최소 선·간격 3px, 대각선 1:1·1:2, 대칭 정리 |
| 5 | 검증본 | 32·48·64px에서 실루엣과 내부 절개 판독 확인 |
| 6 | Unity 임포트 | UI는 Point 필터·밉맵 비활성화, 상태색은 틴트로 적용 |

문장형 원본과 픽셀 보정본을 모두 유지한다. 자동 픽셀 필터는 제작 속도를 높이는 중간 단계이며, 보정 전 결과를 최종 에셋으로 사용하지 않는다.

- `M7-T5`: 특수 주사위 6종 표를 모델·머티리얼 제작 체크리스트로 사용한다.
- `M7-T6`: VFX 프로필 열과 공통 프리셋 표를 이벤트 매핑의 시작점으로 사용한다.
- `M7-T11`: 비활성 카드와 누락 아이콘은 공통 물음표 문양으로 안전하게 폴백한다.

## 5. 확정 결정

1. 삭제된 6개는 전용 아이콘을 만들지 않고 공통 `삭제됨` 문양을 사용한다.
2. 미구현 `strange-die`의 전용 주사위 모델은 M7에서 제작하지 않는다. 카드용 고유 아이콘과 비활성 표시는 유지한다.
3. 아이콘은 레퍼런스의 단색·각진 문장형 시각 문법을 적용하되 개별 도안을 복제하지 않는다.
4. 문장형 원본에 픽셀 필터를 적용하고 64×64px 기준으로 수동 보정한 뒤 32·48·64px에서 검증한다.

## 6. 아이콘 스타일 검토 결과

- 49개 고유 아이콘에 적용할 공통 그래픽 스타일을 아래 3개 견본으로 비교한 뒤 하나를 확정한다.

| 안 | 스타일 | 핵심 표현 | 장점 | 주의점 |
|---|---|---|---|---|
| 1안 | 손그림 문장형 | 굵은 잉크 외곽선, 2~3개 평면색, 최소 명암 | 48~64px 가독성이 좋고 마스크·VFX 재사용과 49종 대량 제작에 유리함 | 입체감은 세 안 중 가장 낮음 |
| 2안 | 각인 룬석형 | 어두운 슬레이트 부조, 넓은 챔퍼, 금색 홈 | 3D 석재 트레이와 가장 자연스럽게 결합됨 | 작은 카드에서 무겁고 세부 홈이 뭉칠 수 있음 |
| 3안 | 에나멜 보석형 | 크림슨·인디고 에나멜 셀, 골드 금속선 | 마법 유물 같은 고급감과 색상 구분력이 큼 | 49개가 동시에 보이면 시각적 경쟁과 제작 복잡도가 커짐 |

사용자 레퍼런스 검토에 따라 1안의 단순한 실루엣을 더 기하학적으로 정리한 **스타일라이즈드 픽셀 문장 아이콘**을 채택한다. 카드 본체와 트레이가 재질감과 입체감을 담당하므로 아이콘은 단순하고 강한 실루엣을 유지한다. 2안의 석재 질감은 비활성·충돌 상태 배지에 제한적으로 재사용할 수 있다.

## 7. M7-T2 구현 결과

- 공통 카드 뷰는 스톤 트레이 내부 슬롯(약 4.58×2.58)의 비율인 `1.774:1` 가로형을 사용한다. Full HD UI 기준 카드 크기는 `460×약 259`이다.
- 웹 레퍼런스는 디자인이 아닌 정보 배치만 참고하며, 상단 종류/상태 → 중앙 아이콘 → 이름 → 구분선 → 한 줄 효과 → 하단 대상 순서로 표시한다.
- 드래프트 카드 3장은 화면 중앙에 같은 크기로 가로 배치하며 카드끼리 겹치지 않는다. 선택 모달은 점수표보다 앞에 표시해 모든 카드 내용을 읽을 수 있게 한다.
- 최종 보정 아이콘은 `Assets/Resources/AugmentIcons/{augmentId}`에 Sprite로 배치하면 자동으로 사용한다.
- 최종 아이콘이 아직 없으면 증강 종류별 64×64 임시 픽셀 문양을 사용하며 텍스처 필터는 Point로 고정한다.
- 임시 문양은 공통 레이아웃과 픽셀 파이프라인 검증용이며 49개 고유 아이콘의 최종 도안을 대신하지 않는다.
